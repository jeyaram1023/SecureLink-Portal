# ❗ Problem Statement 

I am a Team Leader managing around 20–25 members.

Previously, attendance sheets were shared using Excel or Google Sheets. Some users saved old attendance links and marked attendance without attending the meeting.

This created attendance fraud and fake entries.

Problems faced:

- Users reused old attendance links
- Fake attendance entries increased
- Unauthorized users accessed attendance sheets
- Attendance tracking became insecure

---

# ✅ My Solution

To solve this issue, I created a **Secure Attendance Portal**.

This portal uses:

- Dynamic Daily Passwords
- Hidden Secure Links
- Login Attempt Protection
- Automatic Lock System

Only members attending the meeting will know the daily password.

If someone enters the wrong password more than 2 times:

- The system automatically locks
- Access is blocked for 12 hours
- Unauthorized users cannot access the portal

This reduces fake attendance and improves security.
